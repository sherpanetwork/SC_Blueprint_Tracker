Blueprint Owned Status Tool

Extract blueprint names from contracts.ini, track which ones you own, then apply owned markers to matching blueprint lines in global.ini.

1. Upload contracts.ini

No file loaded

Use the contracts.ini file from this repo, or upload a global.ini that contains contract descriptions. The tool reads those descriptions to build the blueprint checklist.

2. Blueprint checklist

0 / 0 owned
Upload contracts.ini to populate the checklist.

3. Import / Export owned list

Use blueprintsOwned.txt to save your owned blueprint list and import it again later. If your uploaded global.ini already has owned markers, those blueprints load automatically.

4. Upload global.ini

No file loaded

Upload your current global.ini, or use global_with_contracts.ini from this repo if you do not already have a modified localization file.

The downloaded result preserves the rest of the uploaded file and only adds owned markers to matching blueprint lines.

Installation details

After downloading the updated global.ini, move it to StarCitizen/LIVE/data/Localization/english/global.ini.

If you already have a user.cfg file, do not overwrite it. Open the existing file and add this line at the end: g_language = english.

If you do not have a user.cfg file, create one in the LIVE folder root with that same line.

StarCitizen/
`-- LIVE/
    |-- user.cfg
    `-- data/
        `-- Localization/
            `-- english/
                `-- global.ini
